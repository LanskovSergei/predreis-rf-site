# Официальные бланки путевых листов (формы № 3 и № 4-С)

Здесь лежат типовые межотраслевые формы Госкомстата (`.xls`), на которые нужно ориентировать PDF.

## Как сейчас работает калькулятор

PDF собирается так: React-разметка (`pdfForms/Form3.tsx`, `Form4c.tsx`) → html2canvas → jsPDF.

Поля и логика совпадают с бланком, но **вёрстка не пиксель-в-пиксель** как в Excel: другие пропорции колонок, упрощённая оборотная сторона 4-С, нет части служебных блоков.

## Как получить PDF «как в жизни» (1:1 с бланком)

1. Один раз экспортировать каждый `.xls` в PDF (лист = A4, книжная / альбомная):
   - Excel: **Файл → Сохранить как → PDF**
   - или скрипт `scripts/export_pdf_blanks.ps1` (нужен установленный Excel)
2. Положить файлы сюда:
   - `form-3-blank.pdf`
   - `form-4c-blank.pdf` (лицо)
   - `form-4c-back-blank.pdf` (оборот, если отдельный лист)
3. В коде включится режим **наложения текста на официальный фон** (`pdfTemplateExport.ts`) вместо html2canvas.

Шаблоны `.xls` из Downloads уже скопированы в эту папку.
